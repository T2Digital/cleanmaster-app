## 📖 Overview | نبذة عن التطبيق
**Clean Master** is a state-of-the-art **Progressive Web Application (PWA)** designed to provide premium cleaning services in Egypt. The platform integrates modern web technologies and Generative AI to deliver a seamless booking experience, real-time invoicing, and interactive customer support.

يُعد **كلين ماستر** تطبيق ويب تقدمي (PWA) متكامل مصمم لتقديم أرقى خدمات التنظيف في مصر. يدمج التطبيق أحدث تقنيات الويب مع الذكاء الاصطناعي (Gemini AI) لتوفير تجربة سلسة لحجز المواعيد بشكل آلي، وإصدار الفواتير، وتقديم خدمة عملاء تفاعلية.

## 🚀 Key Features | أبرز المميزات

- 🤖 **AI-Powered Chatbot**: Integrated with Google Gemini API to handle bookings, calculate exact overall net prices, apply discounts, and interact naturally with users. 
  *(روبوت محادثة ذكي لإدارة الحجوزات، حساب التكلفة الصافية الذكية، والرد الآلي الاحترافي)*
- 📱 **Progressive Web App (PWA)**: Installable directly on any OS (iOS, Android, macOS, Windows) with robust offline caching support. 
  *(تطبيق ويب تقدمي يدعم التثبيت المباشر على الهاتف والعمل بدون إنترنت)*
- ⚡ **Ultra-Fast Performance**: Built on React 19 & Vite for lightning-fast page loads and routing. 
  *(أداء فائق السرعة واستجابة فورية)*
- 🎨 **Premium RTL Interface**: Exquisite Arabic user interface using Tailwind CSS, featuring aesthetic glassmorphism overlays and fluid animations. 
  *(واجهة عربية عصرية وراقية بدعم كامل للتأثيرات البصرية الحديثة)*
- 📲 **WhatsApp Integration**: Generates auto-formated, detailed final invoices routed directly to WhatsApp for order confirmation. 
  *(إصدار آلي للفواتير التفصيلية وإرسالها المباشر للواتساب لتأكيد الحجز)*
- 📍 **Smart Location & Media Capture**: Securely collects precise GPS locations and payment receipt imagery dynamically inside the chatbot. 
  *(تحديد ذكي للموقع الجغرافي ورفع صور إيصالات الدفع والصور الميدانية)*

## 🛠️ Technology Stack | التقنيات الأساسية

- **Frontend Core**: React 19, TypeScript
- **Styling Architecture**: Tailwind CSS (PostCSS)
- **Build Engine & PWA Controller**: Vite, `vite-plugin-pwa`, Workbox
- **AI Brain**: `@google/genai` (Google Gemini 2.5 Flash)
- **Backend & Persistence**: Firebase Services
